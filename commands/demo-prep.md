# /demo-prep

Convert the current sprint's features into slide-ready sprint demo content.

## Steps

1. Gather context:
   - List recently merged PRs or closed issues (ask user for sprint date range or milestone if not obvious)
   - Read PR titles, descriptions, and linked issues for each completed item
2. For each feature, produce:
   - **Headline** (one sentence, non-technical, user benefit framing)
   - **What changed** (two sentences: problem solved, how it was solved)
   - **Demo path** (step-by-step: how to demonstrate the feature live)
   - **Before / After** (if applicable)
3. Organize into a demo script:
   - Opening: sprint goal / theme
   - Feature walkthroughs in priority order
   - Closing: what's next
4. Present the draft to the user
5. Iterate on tone, detail level, or order based on feedback
